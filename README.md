# marine-biotoxin

## Project Progress

### Completed

* Set up the project repository and Python environment.
* Explored marine biotoxin and environmental datasets.
* Investigated YTX measurements and below-detection observations.
* Matched YTX records with environmental measurements using sampling keys.
* Checked missing environmental values.
* Prepared a modeling dataset with 129 measured YTX records and nine environmental features.
* Created a group-aware training/testing split with no shared sampling events.

### In Progress

* Train and evaluate a baseline Random Forest regression model.
* Investigate methods for improving predictions of rare, high-YTX concentrations.

### Research Objective

Investigate whether rare-event-aware machine learning can improve the prediction of high YTX concentrations when extreme observations are scarce.
